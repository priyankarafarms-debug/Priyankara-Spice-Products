PRIYANKARA SPICE PRODUCTS WEBSITE
=================================

FILES
- index.html: website content, contact details, logo and product image link placeholders
- style.css: all colours, layout, responsive design and hero image placeholder

HOW TO USE
1. Keep index.html and style.css in the same folder.
2. Open index.html in a browser to preview.
3. To add your logo, open index.html and replace BOTH occurrences of:
   YOUR_LOGO_IMAGE_URL
   with your logo image URL (or a local file path such as images/logo.png).
4. To add the large hero/background photo, open style.css and replace:
   YOUR_HERO_IMAGE_URL
   with your image URL (or a local path such as images/chilli-banner.jpg).
5. To add the chilli powder photo, open index.html and replace:
   YOUR_CHILLI_POWDER_IMAGE_URL
   with your product photo URL (or local path such as images/chilli-powder.jpg).
6. For local image files, create an "images" folder next to index.html and put your files there.
   Example: images/logo.png, images/chilli-banner.jpg, images/chilli-powder.jpg
7. Edit phone numbers or WhatsApp messages in index.html if needed. WhatsApp links use Sri Lankan
   international format: 94779820212 and 94775201803.

NOTES
- Product price/pack size is intentionally not invented; customers are invited to enquire.
- Registration number is displayed exactly as provided: අනු/9/1/3/05/2005/24
- Google Fonts are loaded online; the site still has fallback fonts if unavailable.
- This is a static website. To publish it, upload both files to a static host such as GitHub Pages,
  Netlify or your hosting provider.
